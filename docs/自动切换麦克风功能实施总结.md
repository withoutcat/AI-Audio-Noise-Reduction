## 🎯 功能概述

实现了"自动切换麦克风"功能，使用 AudioDeviceCmdlets (ADC) PowerShell 模块在降噪启动时自动将系统默认麦克风切换到虚拟麦克风（CABLE Output），停止时恢复原麦克风。

## 🔧 技术实现细节

### 架构图
`
用户勾选复选框
    ↓
MainViewModel.AutoSwitchMic setter
    ↓
[如果正在运行]
    ├─ true  → SwitchToCableOutput()
    └─ false → RestoreOriginalMic()

降噪启动
    ↓
保存原麦克风 ID → _originalDefaultMicId
    ↓
[如果 AutoSwitchMic 启用]
    └─ SwitchToCableOutput()
        ↓
       AudioDeviceSwitcher.SetDefaultCaptureDevice(cableOutput.Id)
        ↓
       Process.Start(powershell.exe, 隐藏窗口)
        ↓
       Import-Module 'native\AudioDeviceCmdlets.dll'
       Set-AudioDevice -ID '<deviceId>'

降噪停止
    ↓
[如果 AutoSwitchMic 启用且有原麦克风]
    └─ RestoreOriginalMic()
        ↓
       AudioDeviceSwitcher.SetDefaultCaptureDevice(_originalDefaultMicId)
`

### 关键设计决策

1. **使用 AudioDeviceCmdlets 而非 COM API**
   - COM IPolicyConfig 方式在某些系统上不可靠
   - ADC 通过 PowerShell 调用 Windows 内部 API，更稳定
   - 已验证可正常切换系统默认麦克风

2. **绝对路径加载模块**
   - 不需要将 ADC 安装到系统 PowerShell 模块目录
   - 避免侵入用户系统
   - 卸载时随应用一起删除，干净无残留
   - 降低被 Windows Defender 误报的风险

3. **隐藏 PowerShell 进程**
   - WindowStyle = Hidden
   - CreateNoWindow = true
   - 用户完全无感知

4. **运行时切换支持**
   - 用户可以在降噪运行时勾选/取消复选框
   - 立即生效，无需重启降噪
   - 提供灵活的用户体验

5. **移除旧的警告逻辑**
   - CheckDefaultDevice() 是妥协方案，现在功能已实现
   - 移除相关 UI 警告，简化界面
   - 减少不必要的系统调用（每2秒检查一次）

## 🐛 已知限制

1. **依赖 PowerShell**
   - 需要系统安装 PowerShell（Windows 10/11 默认已安装）
   - 如果用户禁用了 PowerShell，此功能将失效

2. **延迟**
   - PowerShell 进程启动需要约 200-500ms
   - 对于大多数用户来说可以接受
   - 如果需要更快响应，可考虑直接调用 ADC 的 .NET API（需要更多开发工作）

3. **权限**
   - 切换系统默认麦克风可能需要管理员权限
   - 当前实现使用普通用户权限，应该足够（已验证）
   - 如果遇到权限问题，日志会记录错误
